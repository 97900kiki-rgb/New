# HemoLab — Open DataSet 기반 혈액 분석 WebApp

> 공개 의료 데이터셋(UCI ML Repository · Kaggle)을 활용해 **혈액 검사 데이터를 브라우저에서 바로 분석·시각화**하는 정적 웹 애플리케이션입니다.
> 업로드된 파일은 서버로 전송되지 않고, 파싱·정규화·통계·이상치 탐지·차트 렌더링이 **전부 클라이언트(브라우저)에서** 수행됩니다.

기획 원본: `Open-DataSet-WebAPP.pptx` (슬라이드 1–5) 의 내용을 요구사항으로 삼아 구현했습니다.

## 2. 현재 완료된 기능

### 2.1 데이터 업로드 · 전처리
- 드래그 앤 드롭 / 클릭 업로드 (CSV, TSV, XLSX, XLS, JSON, TXT · 최대 10MB)
- PapaParse 기반 CSV 파싱, SheetJS 기반 Excel 파싱, JSON 레코드 배열 자동 인식
- **컬럼 자동 인식**: 영문 약어·풀네임·한글명·단위 포함 헤더를 정규화해 매핑 (`HGB`, `Hemoglobin`, `헤모글로빈 (g/dL)` 모두 인식)
- **수동 컬럼 매핑 UI**: 인식되지 않은 컬럼을 지표에 수동 연결 후 재분석
- 전처리 항목
  - 숫자 셀에서 수치만 추출 (`12.4 g/dL`, `1,200`, `<0.5` 등)
  - 성별 정규화 (`M/F/Male/Female/남/여` → `남`/`여`)
  - 수치가 없는 행 제외, 결측값은 **지표별 중앙값**으로 대체
  - 지표별 **min-max 정규화(0–1)** 스케일 산출 (다변량 거리 계산용)
  - 모든 처리 과정을 `전처리 로그` 패널에 기록
- 최대 20,000행까지 분석 (브라우저 성능 보호)

### 2.2 통계 분석
- 지표별 평균 · 표준편차 · 중앙값 · 최소/최대 · Q1/Q3 · IQR · P10/P90
- 참고 범위 이탈 건수 (높음/낮음 구분)
- 그룹별 검체 수 · 평균 지표값 · 이상치 기여도 집계

### 2.3 이상치 탐지 (3가지 기법 병행)
| 기법 | 설명 |
|---|---|
| 참고 범위 이탈 | 성별 기준 참고 범위(reference range)를 벗어난 정도를 상대 편차로 환산 |
| 로버스트 Z-score (MAD) | 중앙값·MAD 기반 표준화 편차 — 임계값 슬라이더로 조정 (기본 2.5) |
| IQR 1.5× 규칙 | Q1−1.5·IQR / Q3+1.5·IQR 밖의 값을 탐지 |
| 다변량 거리 (RMS Z) | 여러 지표가 동시에 치우친 검체를 다차원 거리로 탐지 (단일 항목 검사로 놓치기 쉬운 케이스) |

- 심각도 자동 분류: **높음(≥2.5) / 중간(≥1.5) / 낮음**
- 각 이상치에 대해 **탐지 근거(사용된 기법과 점수)** 를 그대로 노출

### 2.4 실시간 시각화 (Chart.js 6종)
1. `주요 지표 분포` — 지표별 참고 범위(부동 막대) + 전체 평균 + 최소/최대
2. `지표별 정상/이상 비율` — 정상·낮음·높음 누적 막대
3. `헤모글로빈 × 백혈구 산점도` — 그룹별 색상, 이상치 검체는 크기·테두리로 강조
4. `이상치 항목 Top 8` — 가로 랭킹 막대
5. `지표별 이상치 개수` / `검체별 이상치 개수` — 탐지 화면 전용 차트
6. `검체 상세 레이다` — 검체 1건의 지표가 참고 범위 중앙(100%) 대비 어디에 있는지

### 2.5 검체 탐색
- 검색(검체 ID · 그룹 · 성별), 그룹 필터, 상태 필터(정상/이상치 포함), 정렬 6종
- 페이지네이션 (25건 단위), 이상치 개수 태그
- 참고 범위를 벗어난 셀은 **색상 + ▲/▼ 마커**로 하이라이트
- 행 클릭 → **검체 상세 모달** (기본 정보, 지표별 값·참고범위, 탐지 근거, 레이다 차트)

### 2.6 기록 저장 (RESTful Table API)
- 분석 결과를 이름·출처·메모와 함께 저장 (요약 통계 + 최대 200건 검체)
- 저장 목록 조회 · 불러오기(대시보드 즉시 갱신) · 삭제
- 최초 실행 시 예시 기록 1건이 포함되어 있어 저장 기능을 바로 체험 가능

### 2.7 내장 데이터
- **기본 자동 로드**: 시뮬레이션 데이터 180건 (seed 고정 → 재현 가능, 첫 화면이 비지 않음)
- **시뮬레이션 데이터 생성**: 공개 혈액 데이터셋의 컬럼 구조·분포 특성을 참고한 통계적 생성
  - 지표 간 생리적 상관관계 반영 (HCT ≈ HGB×3, RBC ≈ HGB/3.2, MCV ≈ HCT/RBC×10)
  - 정상군/경계군/주의군 3그룹, 참고 범위 이탈 비율 약 6% 내외
- **샘플 CSV · 업로드용 템플릿 다운로드** (한글 Excel 대응 BOM 포함)

### 2.8 UI/UX
- 다크 메디컬 테마, 6개 탭(대시보드 / 데이터 / 검체 목록 / 이상치 탐지 / 저장된 기록 / 프로젝트 소개)
- 해시 기반 뷰 라우팅 (`#dashboard`, `#outliers` … → 새로고침·링크 공유 시 해당 뷰 유지)
- 반응형: 데스크톱 3열 → 태블릿 2열 → 모바일 1열, 모바일 헤더 가로 스크롤 내비게이션
- 접근성: 시맨틱 태그, `aria-label` / `aria-live`, 키보드 조작(드롭존·행·탭), `Esc`로 모달 닫기, `prefers-reduced-motion` 대응
- 토스트 알림, 전역 오류 피드백 메시지

## 4. 주요 진입 URI 및 파라미터

단일 페이지(SPA)이므로 모든 화면은 `index.html` + 해시로 접근합니다.

| 경로 | 화면 | 설명 |
|---|---|---|
| `index.html` (또는 `#dashboard`) | 대시보드 | KPI 5종, 차트 4종, 기술통계표, 이상치 미리보기 |
| `index.html#data` | 데이터 | 업로드, 컬럼 매핑, 미리보기, 전처리 로그 |
| `index.html#samples` | 검체 목록 | 검색·필터·정렬·페이지네이션 |
| `index.html#outliers` | 이상치 탐지 | 3중 탐지 결과, Z 임계값 조정, 다변량 이상 검체 |
| `index.html#saved` | 저장된 기록 | 저장 폼 + 저장 목록 (불러오기/삭제) |
| `index.html#about` | 프로젝트 소개 | 배경 · 목표 · 공개 데이터 출처 · 지표 참고범위표 |

### 테이블 API (앱 내부에서 fetch 로 호출)
| 메서드 | 경로 | 용도 |
|---|---|---|
| `GET` | `tables/analysis_records?limit=100&sort=-created_at` | 저장된 분석 기록 목록 |
| `POST` | `tables/analysis_records` | 현재 데이터셋 저장 |
| `DELETE` | `tables/analysis_records/{id}` | 기록 삭제 |

### 업로드 파일 헤더 규격 (권장)
```
SampleID, Sex, Age, Group, HGB, HCT, RBC, WBC, PLT, MCV, MCH, MCHC, RDW,
NEUT, LYMPH, MONO, EOS, BASO, CRP, ESR, GLU, CHOL, CREA, FER
```
- `Sex`/`Age`/`Group`/`ID` 는 선택 항목입니다. 없으면 성별은 `미상`, 그룹은 `미분류`, ID는 자동 부여됩니다.
- 헤더명은 영문 약어·풀네임·한글명 모두 자동 인식되며, 인식 실패 시 `컬럼 매핑`에서 직접 지정할 수 있습니다.

## 5. 데이터 모델

### 5.1 테이블: `analysis_records` (저장된 분석 기록)

| 필드 | 타입 | 설명 |
|---|---|---|
| `id` | text | 레코드 ID (시스템 관리) |
| `label` | text | 분석 이름 |
| `source` | text | 데이터 출처 (UCI / Kaggle / 자체 수집 등) |
| `note` | text | 메모 |
| `metric_keys` | array | 사용된 지표 키 목록 (예: `["hgb","wbc","plt",…]`) |
| `sample_count` | number | 저장된 검체 수 |
| `abnormal_count` | number | 이상치 총 건수 |
| `outlier_rate` | number | 이상치 비율(%) |
| `z_threshold` | number | 탐지에 사용한 Z 임계값 |
| `stats` | rich_text | 지표별 요약 통계 JSON |
| `dataset_json` | rich_text | 검체 데이터 JSON (최대 200건, 초과 시 `truncated: true`) |
| `saved_at` | datetime | 저장 시각 |

시스템 필드(`gs_project_id`, `gs_table_name`, `created_at`, `updated_at`)는 플랫폼이 자동 관리합니다.

### 5.2 내부 데이터 구조 (브라우저 메모리)
```js
// 검체 레코드
{ id: 'S-1001', sex: '여', age: 44, group: '정상군 / 일반 검진',
  values: { hgb: 13.4, hct: 40.2, rbc: 4.42, wbc: 6.2, plt: 245, /* …20개 지표 */ } }

// 이상치 항목
{ sampleId, group, sex, metricKey, metricLabel, metricCode, unit,
  value, refMin, refMax, refText, score, severity, direction, methods: [] }
```

### 5.3 저장소
- **브라우저 메모리**: 업로드 파일의 파싱·분석 결과 (새로고침 시 초기화 — 개인정보 보호 측면에서 의도된 동작)
- **RESTful Table API (`analysis_records`)**: 사용자가 명시적으로 저장한 분석 요약 및 검체 데이터

## 6. 지원 지표 및 참고 범위 (요약)

| 코드 | 지표 | 단위 | 일반 참고 범위 |
|---|---|---|---|
| HGB | 헤모글로빈 | g/dL | 남 13.5–17.5 / 여 12.0–15.5 |
| HCT | 헤마토크릿 | % | 남 40–52 / 여 36–46 |
| RBC | 적혈구 수 | 10⁶/µL | 남 4.3–5.8 / 여 3.8–5.2 |
| WBC | 백혈구 수 | 10³/µL | 4.0–11.0 |
| PLT | 혈소판 | 10³/µL | 150–450 |
| MCV | 평균 적혈구 용적 | fL | 80–100 |
| MCH | 평균 적혈구 혈색소량 | pg | 27–33 |
| MCHC | 평균 적혈구 혈색소농도 | g/dL | 32–36 |
| RDW | 적혈구 분포 폭 | % | 11.5–14.5 |
| NEUT / LYMPH / MONO / EOS / BASO | 백혈구 감별 | % | 40–70 / 20–45 / 2–10 / 1–6 / 0–1 |
| CRP | C-반응성 단백 | mg/L | 0.1–5.0 |
| ESR | 적혈구 침강 속도 | mm/hr | 0–20 |
| GLU | 공복 혈당 | mg/dL | 70–100 |
| CHOL | 총 콜레스테롤 | mg/dL | 200 이하 |
| CREA | 크레아티닌 | mg/dL | 0.6–1.2 |
| FER | 페리틴 | ng/mL | 30–300 |

> ⚠️ 참고 범위는 검사실 · 장비 · 성별 · 연령에 따라 달라집니다. 본 앱은 **학습·연구용**이며 의학적 진단을 제공하지 않습니다.

## 7. 미구현 / 제약 사항

- **서버 사이드 처리 없음**: 대용량 파일의 서버 사전 처리, 분석 작업 큐, 결과 캐싱은 지원하지 않습니다 (정적 사이트 한계).
- **인증/계정 없음**: 저장 기록은 프로젝트 단위로 공유됩니다. 사용자별 비공개 저장이나 접근 제어는 없습니다.
- **파일 크기 제한 10MB / 분석 상한 20,000행**: 초과분은 잘라내고 로그로 안내합니다.
- **저장 시 상위 200건만 보관**: 원본 전체를 서버에 보관하지 않으므로 저장 기록을 불러오면 검체 수가 줄어들 수 있습니다.
- **살아있는 실시간 스트리밍 없음**: 업로드 시점 기준 분석이며, 파일 변경을 감시하지 않습니다.
- **의료 진단 기능 없음**: 질환명 예측·판정 모델은 포함하지 않습니다 (이상치 탐지까지만 제공).

## 8. 다음 개발 단계 제안

1. **비교 분석 뷰** — 저장된 기록 2건 이상을 나란히 비교(그룹별 평균 변화, 이상치 증감 추이).
2. **시계열 지원** — 검체에 검사일자를 추가해 개인/그룹의 지표 추이 라인 차트 제공.
3. **리포트 내보내기** — 현재 분석 결과를 인쇄용 레이아웃(`@media print`) 또는 CSV 요약으로 내보내기.
4. **참고 범위 커스터마이징** — 검사실별 참고 범위를 화면에서 직접 수정·프리셋 저장.
5. **연령 보정 범위** — 소아/노인 구간별 참고 범위 적용.
6. **PWA 전환** — 오프라인 사용과 홈 화면 설치 지원 (Service Worker + Web App Manifest).
7. **이상치 사유 태깅** — 탐지된 이상치에 사용자가 코멘트를 달아 저장 기록에 포함.
8. **접근 제어** — 저장된 분석 기록을 조직 구성원만 열람하도록 Hosted 접근 규칙 설정.

## 9. 실행 및 배포

### 로컬 실행
정적 사이트이므로 정적 서버로 열면 됩니다. (`file://` 로 직접 열면 테이블 API fetch가 동작하지 않습니다.)
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

### 배포
플랫폼의 **Publish 탭**에서 원클릭으로 배포할 수 있습니다.
- 정적 파일(`index.html`, `css/`, `js/`)이 그대로 호스팅됩니다.
- 테이블 스키마(`analysis_records`)는 배포 시 D1 데이터베이스로 프로비저닝됩니다.
