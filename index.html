    프로젝트 소개

    공개 의료 데이터셋을 활용한 개인 프로젝트 — 혈액 검사 데이터를 웹에서 분석하고 시각화합니다.

    왜 필요한가

    혈액 검사 데이터는 방대하지만, 이를 효율적으로 분석할 수 있는 도구가 부족합니다.

    공개 데이터 활용

    UCI ML Repository, Kaggle 등 공개 의료 데이터셋으로 학습과 개발을 동시에 실현합니다.

    웹 기반 접근성

    브라우저만 있으면 언제 어디서나 혈액 데이터 분석이 가능한 환경을 제공합니다.

    프로젝트 목표

    세 가지 목표를 기준으로 기능을 설계했습니다.

    1. 1

      혈액 분석 시스템 구축

      Open DataSet 기반으로 실질적인 혈액 분석 파이프라인을 설계하고 구현합니다.
      구현: 컬럼 자동 인식 → 정규화 → 기술 통계 → 이상치 탐지 → 시각화 파이프라인

    2. 2

      사용자 친화적 인터페이스

      누구나 쉽게 사용할 수 있는 직관적인 웹 UI/UX를 제공합니다.
      구현: 드래그 앤 드롭 업로드, 한글 라벨, 반응형 레이아웃, 키보드 접근성

    3. 3

      실시간 시각화

      분석 결과를 즉시 차트와 그래프로 확인할 수 있는 실시간 대시보드를 구현합니다.
      구현: Chart.js 기반 분포·상태·산점도·랭킹 차트, 필터 변경 즉시 재렌더링

    주요 기능

    요구사항 매핑

    • 데이터 업로드 및 분석

      CSV · Excel · JSON 파일을 올리면 전처리 후 자동으로 분석이 시작됩니다.

    • 통계 분석 및 이상치 탐지

      정상 범위 이탈, IQR, 다변량 거리 기반으로 비정상 수치를 감지·하이라이트합니다.

    • 실시간 시각화

      필터와 임계값을 바꾸면 차트가 즉시 다시 그려집니다.

    • 기록 보관

      분석 결과를 저장하고 다시 불러와 비교할 수 있습니다.
